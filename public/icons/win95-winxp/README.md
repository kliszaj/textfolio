# Windows 95–XP icon SVGs

These SVGs were generated from the `.ico` files in the
[trapd00r/win95-winxp_icons](https://github.com/trapd00r/win95-winxp_icons/tree/master/icons)
collection using the
[jessefalzone/ico-to-svg](https://github.com/jessefalzone/ico-to-svg) converter.

- Source inputs: 1,189 `.ico` files
- Generated outputs: 4,675 SVG variants (size and bit-depth variants retained)
- Conversion date: 2026-08-30

The source directory also contains `.icl`, `.ani`, and `.png` files; the
requested converter accepts `.ico` inputs, so those files are not represented
in this SVG set.
